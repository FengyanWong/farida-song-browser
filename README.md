# 法里达 · 歌切收藏

轻量的哔哩哔哩歌切收藏工具。中文深色界面，显示封面、标题、UP 主和上传时间；点击标题即可在页面内播放，也可打开原视频。

**[下载 Windows 版 v0.0.5](https://github.com/FengyanWong/farida-song-browser/releases/download/v0.0.5/FaridaSongBrowser-0.0.5-windows-x64.exe)** · [全部下载与更新说明](https://github.com/FengyanWong/farida-song-browser/releases/latest)

## 开始使用

1. 双击 EXE，无需安装 Python。页面自动打开，应用在后台运行，不显示终端窗口。
2. 首次用哔哩哔哩手机 App 扫码登录。之后有效登录会自动使用，每次启动更新一次来源。
3. 搜索歌名并播放，或勾选歌曲建立自己的歌单。退出时点击右上角账号菜单 → **退出应用**。

关闭最后一个应用标签页后约 5 秒自动退出。刷新页面、切换标签页不会退出；再次双击 EXE 即可重新打开。

## 源码版 v0.0.11 的功能与来源

- **两个页面**：片段收藏、采集来源。可按歌名、UP 主、BV 号或 B 站视频链接搜索；带 `?p=2` 的链接只显示第 2 P。片段详情可复制原视频链接。跨页勾选的片段可一起播放、加入歌单或批量收录。切换筛选条件会清空选择。支持星标和 CSV 导出。「最近发现的原视频」按目录首次发现时间排序，方便找到刚收录的旧投稿。
- **采集状态**：每个来源显示上次成功更新、最近尝试、新增片段数和未完成原因；遇到访问限制可稍后继续任务。
- **歌单内搜索**：在播放队列或编辑歌单时按歌名、UP 主、原视频标题查找，保留原播放顺序；编辑歌单时可拖动调整顺序，也可使用上下移按钮。
- **备份与恢复**：右上角账号菜单可导出或恢复本机数据，包含歌曲、来源、歌单、收藏、备注、最近播放和播放器设置；不包含登录凭据。恢复前自动保留一份备份。
- **播放恢复**：临时连接故障自动尝试恢复一次，重试保留歌曲进度；可开启跳过失效视频，登录失效或访问限制时暂停。
- **播放模式与记忆**：支持随机播放、列表循环和单曲循环；重新打开后点击「继续播放」恢复上次歌曲与位置，音量、静音和播放器展开状态也会记住。
- **浏览与回听**：可折叠显示同歌版本，在「最近播放」查找最近 100 首；向下浏览时显示迷你播放条。支持的浏览器可用耳机或系统媒体键切歌。
- **连续播放与歌单**：播放当前筛选下的所有歌曲，或创建、编辑本地歌单。使用已登录账号在线播放，音视频不保存为本地文件。
- **随附目录**：1,075 个视频、1,286 条片段（其中 1,037 条已收录），以及 1,077 个不同 BV 链接。[目录详情](data/README.md)
- **默认来源**：离落、CLANNADOR、阿见、稻草仁尔，以及同时带有「法里达」「直播切片」标签的视频。
- **歌单同步**：每次更新读取 [小法的歌单](https://fareeda.songlist.cc/)，感谢 **CLANNADOR** 整理。
- **Frida 小伙伴**：默认附带，支持 v1 / v2 精灵图，可隐藏或关闭动画。

目录和收藏保存在本机 `%LOCALAPPDATA%\FaridaSongBrowser`。升级保留已有数据；发行包不含个人登录信息、歌单、星标或备注。
