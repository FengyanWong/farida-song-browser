# 法里达 · 歌切收藏

轻量的哔哩哔哩歌切收藏工具。中文深色界面，显示封面、标题、UP 主和上传时间；点击标题即可在页面内播放，也可打开原视频。

**[下载 Windows 版 v0.0.5](https://github.com/FengyanWong/farida-song-browser/releases/download/v0.0.5/FaridaSongBrowser-0.0.5-windows-x64.exe)** · [全部下载与更新说明](https://github.com/FengyanWong/farida-song-browser/releases/latest)

## 开始使用

1. 双击 EXE，无需安装 Python。页面自动打开，应用在后台运行，不显示终端窗口。
2. 首次用哔哩哔哩手机 App 扫码登录。之后有效登录会自动使用，每次启动更新一次来源。
3. 搜索歌名并播放，或勾选歌曲建立自己的歌单。退出时点击右上角账号菜单 → **退出应用**。

关闭最后一个应用标签页后约 5 秒自动退出。刷新页面、切换标签页不会退出；再次双击 EXE 即可重新打开。

## 源码版 v0.0.17

- **找歌**　按歌名、UP 主、BV 号或视频链接搜索。「法里达」「法里達」「Fareeda」「Farida」都可找到同一批结果。带 `?p=2` 的链接会定位到第 2 P。可合并同歌版本，也可按本地上传日期或「最近发现的原视频」查找。
- **选歌**　点列名可排序，再点一次可反向。点页码可直接跳页。跨页勾选后可播放、加入歌单或批量收录。往返「采集来源」会保留勾选，切换筛选条件会清空选择。
- **播放**　支持连续播放、随机、循环和上次进度。在歌单编辑器可复制或粘贴 B 站链接，匹配本机已有片段。歌单可搜索和拖动排序，在播放队列中用方向键选歌、回车播放。浏览时仍可用迷你播放条或系统媒体键切歌。
- **采集与备份**　「采集来源」显示每个来源的进度和上次成功时间。中断后可继续任务。来源提供重试时间时，会显示本机时间。右上角账号菜单可导出完整 JSON 备份，恢复文件上限为 64 MiB。登录凭据单独保存在本机。
- **Frida 小伙伴**　默认附带，支持 v1 / v2 精灵图，可隐藏或关闭动画。

## 目录与来源

随附目录有 **1,037 个已收录片段**，共 1,286 条候选片段、1,077 个不同 BV 链接。[目录详情](data/README.md)

默认采集离落、CLANNADOR、阿见、稻草仁尔的投稿，以及同时带有「法里达」「直播切片」标签的视频。启用整理歌单时，更新会先读取 **CLANNADOR** 的公开索引，再按顺序查 B 站视频。来源卡片的「查看待补全链接」可打开索引中尚无本机视频资料的条目。[小法的歌单](https://fareeda.songlist.cc/)

目录、歌单和收藏保存在本机 `%LOCALAPPDATA%\FaridaSongBrowser`。升级会保留已有数据。
