# 法里达 · 歌切收藏 v0.0.4

关闭最后一个应用标签页后，后台约 5 秒自动退出，正在进行的采集也会停止并保留已保存进度。

- 刷新页面时留出重连时间，不会立即退出。
- 打开多个应用标签页时，关闭其中一个不会影响其他页面。
- 切换标签页或最小化浏览器会继续运行。
- 登录界面同样支持关闭后自动退出；仍可使用「退出应用」立即关闭。

Windows x64，无需安装 Python。升级前退出旧版，再打开新 EXE；已有目录、收藏和登录信息会保留。
随附目录仍包含 1,286 条片段、1,075 个原视频和 1,077 个 BV 链接。
歌单整理署名：[CLANNADOR · 小法的歌单](https://fareeda.songlist.cc/)。软件许可为 GPL-3.0-only。
