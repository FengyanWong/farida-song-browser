# 法里达 · 歌切收藏 v0.0.1

首个公开版本。适用于 Windows x64，下载 EXE 后双击运行，无需安装 Python。
界面在系统默认浏览器中打开；使用期间请保持小启动窗口开启。

- 中文深色界面，片段收藏和采集来源两个页面。
- 显示封面、标题、UP 主和上传时间；点击标题打开哔哩哔哩对应分 P。
- 四个配置的 UP 主、法里达／直播切片标签发现、CLANNADOR 歌单更新。
- 哔哩哔哩扫码登录，本机加密保存会话；每次启动验证登录后更新一次来源。
- 本地搜索、筛选、收藏、收录确认、CSV 导出和可恢复的采集进度。
- 默认 Frida 小伙伴，支持 v1／v2 精灵图导入。

随附真实采集目录：**1,286 条片段 / 1,075 个原视频**，其中已收录 **1,037** 条。
去重后的 TXT 包含 **1,077 个 BV 链接**，保留两个未能加载视频信息的歌单引用。
CSV 包含所有状态的片段和分 P 链接。歌单整理署名 **CLANNADOR**：https://fareeda.songlist.cc/。
目录在新电脑首次启动时自动载入，不覆盖已有数据。账号、Cookie、星标和私人备注不在发行包内。

## 下载文件

- `FaridaSongBrowser-0.0.1-windows-x64.exe`：单文件应用。
- `FaridaSongBrowser-0.0.1-windows-x64.zip`：应用、说明、目录和第三方许可文本。
- `bilibili-clips-0.0.1.csv`：完整片段清单（含上传时间和状态）。
- `bilibili-links-0.0.1.txt`：去重后的原视频链接。
- `catalog-0.0.1.json`：随附目录的结构化快照。
- `FaridaSongBrowser-0.0.1-dependency-sources.zip`：所用依赖和构建工具的源代码包及校验信息。
