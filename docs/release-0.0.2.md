# 法里达 · 歌切收藏 v0.0.2

双击 EXE 后直接打开浏览器，应用在后台运行，不再显示终端窗口。

- 账号菜单和登录界面新增「退出应用」，可停止后台运行并保留已保存的目录、收藏与登录。
- 关闭网页后仍可继续采集；再次双击 EXE 可重新打开现有应用。
- 启动错误会显示提示，诊断输出保存在本机数据目录的 `launcher.log`。
- 简化中文 README，开发与打包步骤移至独立文档。

随附目录保持不变：1,286 条片段、1,075 个原视频，TXT 包含 1,077 个不同 BV 链接。
歌单整理署名：[CLANNADOR · 小法的歌单](https://fareeda.songlist.cc/)。

Windows x64，下载 EXE 即可使用，无需安装 Python。升级前先关闭旧版启动窗口，已有数据会保留。
也可下载 ZIP（应用、说明和目录），或单独下载 CSV、TXT、JSON 目录。
对应版本源码、依赖源码包和 SHA-256 校验值随发行版提供。软件许可为 GPL-3.0-only。
