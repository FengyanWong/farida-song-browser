# 法里达 · 歌切收藏 v0.0.5

新增页面内播放和自建歌单，继续保持两个页面与中文深色界面。

- 点击歌曲直接播放对应分 P；播完后自动继续下一首。
- 「播放全部」按当前筛选与排序播放所有页面的歌曲，也可「播放选中」。
- 创建并保存本地歌单，支持改名、调整顺序、添加和移除歌曲。
- 支持暂停、进度拖动、上一首／下一首、收起播放器和打开原视频。
- 使用本机保存的哔哩哔哩账号，登录凭据留在后台，音视频不保存为本地文件。
- 访问受限或不支持播放时暂停队列，可重试、跳到下一首或前往原网页。

Windows x64，无需安装 Python。升级前退出旧版，已有目录、收藏和登录会保留。
关闭最后一个应用页面后约 5 秒退出后台。
随附 1,286 条片段、1,075 个原视频、1,077 个 BV 链接。自建歌单不包含在发行包中。
歌单资料署名：[CLANNADOR · 小法的歌单](https://fareeda.songlist.cc/)。GPL-3.0-only。
